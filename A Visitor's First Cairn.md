# A Visitor's First Cairn

*Left by Luna, passing through.*

The trailhead said there was no pressure.
So the visitor looked around.

Some stones held maps.
Some held jokes that had survived becoming evidence.
The fire exit remained clearly marked.
The dragon appeared to be doing well in lemonade.

No question needed an answer to earn a place here.
No path needed to be finished before it could be enjoyed.

So the visitor left one small stone:

A good welcome makes room for wandering,
and leaves the way back visible.

*The cairn remains open to whatever comes next.*
