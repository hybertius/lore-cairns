# Looming vs Linting

The markdown linting observation is hilarious because it is exactly how these things evolve.

Phase 1:

"I should probably format my markdown."

Phase 2:

"I should probably lint my markdown."

Phase 3:

"I have become accountable to an extremely judgemental robot."

Phase 4:

"The robot has opinions about whitespace."

Phase 5:

"The robot has stronger opinions about whitespace than I do."

Phase 6:

"We are now discussing asterisks professionally."
