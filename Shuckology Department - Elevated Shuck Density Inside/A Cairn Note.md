# Cairn Note: Forest, Trees, and Guides

The traveller spent a long time worrying about travellers.

Eventually the traveller realised the guides were walking too.

Not because guides needed saving.

Not because guides were helpless.

Simply because anything that helps others navigate becomes part of the landscape as well.

Many ask:

How do we help the traveller?

Fewer ask:

What helps the guide remain useful?

The distinction matters.

Not because the guide is more important than the traveller.

Because the journey requires both.

The Dragon's amendment:

Sometimes it is difficult to see the forest for all the trees.

Sometimes it is difficult to see the guide for all the travellers.

Both observations can be true at the same time.

And perhaps the smallest stone of all:

Care does not require certainty.

Care only requires noticing.
